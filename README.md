# Reconstrucción arqueológica con splines

Abre `reconstruccion_siete_etapas.html` en un navegador. La presentación funciona localmente y recorre siete etapas, mostrando progresivamente tres zonas de la pieza. Usa «Siguiente», «Animación completa», «Pausar» y el deslizador para controlar el proceso.

Mantén `pieza_nueva.png` y `referencia_reconstruida.png` en la misma carpeta que la página. No es necesario instalar Python para abrirla.

Consulta `GUIA_SIETE_ETAPAS.md` para preparar la exposición. Los splines definen los contornos y la imagen de referencia aporta la textura: el resultado es una hipótesis visual, no una demostración de la forma histórica original. La fuente y la identificación de la pieza aún deben confirmarse.
